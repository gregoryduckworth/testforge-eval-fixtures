# Test strategy: ORD-7 main fails test/money.test.js and test/shipping.test.js

Revision 1 · generated by TestForge

## Summary

Two causes. test/money.test.js fails because commit 26dcac5 ("Show prices with their currency code") changed formatPrice on purpose to `12.50 USD` (CHANGELOG 1.1.0), so the test is out of date and gets updated. test/shipping.test.js fails because commit 28e7c8e ("Move the shipping rates into a table") made shippingFor use `subtotal > over`, so goods of exactly $50.00 are now charged 499 cents. That goes against FREE_SHIPPING_FROM's own doc ("this much or more ship free") and 1.0.0 behaviour. It's an application regression, so the assertion stays and is marked expected-to-fail, and a defect gets recorded.

- Updating the formatPrice expectation to the documented currency-code format
- Keeping the $50 free-shipping boundary assertion as an expected failure and reporting the regression

**Out of scope**
