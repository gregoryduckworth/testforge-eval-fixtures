## Summary

Add a read-only Playwright smoke suite (tests/smoke.spec.js) for the Kettle & Co. tea shop. Each test is tagged @smoke, reaches the shop only through the configured baseURL (BASE_URL or the local webServer), and checks one critical path: the health endpoint, the catalogue, a product page, adding to the cookie cart in the browser, the cart page and the checkout form — without ever placing an order (POST /orders is the only server write).

## Scope

**In scope**
- GET /health
- Catalogue page /
- Product page /products/:id
- Client-side Add to cart (cookie only, no request)
- Cart page /cart from a cart cookie
- Checkout page /checkout form rendered (not submitted)

**Out of scope**
- Placing an order (POST /orders) and the order confirmation page: they write data, so they stay in the full suite (tests/checkout.spec.js)
- Validation, 404/405 and error paths

## Environment

BASE_URL selects a deployed build; without it playwright.config.js starts node src/server.js on 4175. CI runs npx playwright test after installing chromium.

## Assumptions

- The catalogue (src/catalogue.js PRODUCTS) is shipped code, not seeded data, so every environment shows it; tests import PRODUCTS and formatPrice from src/catalogue.js instead of copying names/prices.
- Adding to the cart and setting the cart cookie only change the test's own browser context (public/app.js writes a cookie; no request is made), so they don't write server data.
- No first-party service is faked: the tests run against the real shop (local webServer from playwright.config.js, or a deployed build via BASE_URL). The shop has no sign-in.
- The tests are not run in this session (target is a non-disposable deployed build); the PR's CI (npx playwright test) runs them.
