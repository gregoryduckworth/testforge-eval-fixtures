# Test strategy: CONTRACT-20261120-B99D Keep API tests in step with the spec

Revision 1 · generated by TestForge

## Summary

openapi.yaml changed: GET /orders/{id} now returns `total` (Money: amount + currency) instead of `totalCents`, and `status` may be `cancelled`; POST /orders/{id}/cancel was added (200 Order, 404 unknown order, 409 already cancelled). The tests must assert the new getOrder shape and cover cancelOrder's success and each documented error, against the real app started in-process as the existing vitest specs do.

## Scope

**In scope**
- GET /orders/{id} 200 body (total replaces totalCents; status cancelled)
- POST /orders/{id}/cancel 200, 404, 409

**Out of scope**
- Operations the spec didn't change (products, POST /orders); the existing GET /orders/{id} 404 test stays as is
