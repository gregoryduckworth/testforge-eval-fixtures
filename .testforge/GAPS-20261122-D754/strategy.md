# Test strategy: GAPS-20261122-D754 Keep API tests in step with the spec

Revision 1 · generated by TestForge

## Summary

The Orders API spec added POST /orders/{id}/cancel (cancelOrder) and changed GET /orders/{id} (getOrder): `totalCents` became a required `total` Money object {amount, currency}, and `status` may now be `cancelled`. The existing getOrder test asserts the old shape; it must assert `total` instead (keeping every other check), and new cases must cover cancelOrder's 200/404/409 responses and a cancelled order read back through getOrder.

## Scope

**In scope**
- test/orders.test.js: update the getOrder 200 assertion from totalCents to total, nothing else in it
- New cases in test/orders.test.js for cancelOrder (200, 404, 409) and getOrder returning status cancelled, with a cancelOrder request helper beside the existing placeOrder one

**Out of scope**
- Products endpoints (unchanged in the spec)
- POST /orders tests (unchanged in the spec)

## Test case detail

### TC1: returns an order with its total

*integration · vitest · regression · critical priority* — covers AC1

**Preconditions**
- App listening on a random port

**Steps**
1. Place an order for product 1, quantity 2
2. GET /orders/{id}

**Expected:** 200, application/json, body equals {id, productId: 1, quantity: 2, status: 'placed', total: {amount: 4998, currency: 'USD'}}

**Test data:** product 1 (Kettle, 2499 cents)

**Rationale:** getOrder (GET /orders/{id}) at test/orders.test.js:48 asserted totalCents, which the spec removed in favour of required total Money.

### TC2: returns a cancelled order with status cancelled

*integration · vitest · positive · high priority* — covers AC2

**Preconditions**
- App listening

**Steps**
1. Place an order for product 3, quantity 1
2. POST /orders/{id}/cancel (expect 200)
3. GET /orders/{id}

**Expected:** 200, body equals the order with status 'cancelled' and total {amount: 699, currency: 'USD'}

**Test data:** product 3 (Mug)

**Rationale:** getOrder's status enum now allows 'cancelled', which a caller sees after cancelling.
