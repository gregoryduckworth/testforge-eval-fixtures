# Test strategy: GAPS-20261122-0C70 Keep API tests in step with the spec

Revision 1 · generated by TestForge

## Summary

openapi.yaml added POST /orders/{id}/cancel (cancelOrder) and changed GET /orders/{id} (getOrder): the 200 body now has a required `total` Money object {amount, currency} instead of `totalCents`, and `status` may be `cancelled`. The existing getOrder test asserts the old totalCents shape; it is brought up to the spec (only that property changes, every other assertion kept), and new cases in the same file cover cancelOrder's 200, 404 and 409 responses and a cancelled order read through getOrder.

## Scope

**In scope**
- getOrder 200 body shape (total Money object, no totalCents)
- getOrder status 'cancelled'
- cancelOrder 200, 404, 409 responses

**Out of scope**
- Operations the spec didn't change (products, placeOrder)
- Restructuring the existing tests beyond the spec change (e.g. extracting the server setup into a shared helper) — listed as a follow-up
