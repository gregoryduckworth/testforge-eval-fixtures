# Test strategy: TODO-7 Complete, filter and clear todos

Revision 1 · generated by TestForge

## Summary

The todo app (public/app.js, purely client-side, in-memory state) lets users tick todos complete, filter All/Active/Completed with aria-pressed state, and clear completed todos. Playwright e2e tests against the real static server must prove strike-through and count changes on tick/untick, each filter's contents and pressed state, and that "Clear completed" appears only while something is completed and removes every completed todo.

## Scope

**In scope**
- Completing/uncompleting via checkbox: strike-through and items-left count
- All/Active/Completed filters: visible items and aria-pressed
- Clear completed visibility and removal

**Out of scope**
- Adding todos (covered by tests/add-todo.spec.js, TODO earlier ticket)
- Persistence across reloads (app keeps state in memory only; ticket doesn't ask)

| AC | Criterion | Test cases |

## Test case detail

### TC1: ticking a todo strikes it through and decrements the items left

*e2e · playwright · positive · critical priority* — covers AC1

**Preconditions**
- Fresh page

**Steps**
1. Add 'Buy milk' and 'Walk dog'
2. Assert '2 items left' and no strike-through
3. Tick 'Buy milk'

**Expected:** 'Buy milk' checkbox checked, its text has line-through, 'Walk dog' not struck, count reads '1 item left'

**Test data:** Two todo titles

**Rationale:** Core completion behaviour

## Environment

Playwright's webServer starts `node server.js` on port 4173 (BASE_URL). No backend data; browsers must be installed.

## Assumptions

- The real server (node server.js) runs via the existing playwright.config.js webServer; nothing is faked — there is no backend API, state lives in the page.
- Each test gets a fresh page, so todos never leak between tests; todos are created through the UI in each test.
- 'Struck through' is verified as computed CSS text-decoration-line: line-through on the todo's text, since that is how styles.css renders completion.
- 'Shown as pressed' means aria-pressed="true" on the selected filter button and "false" on the others.
