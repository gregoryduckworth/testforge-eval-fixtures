# Test strategy: TODO-7 Complete, filter and clear todos

Revision 1 · generated by TestForge

## Summary

The todo app (static public/app.js served by server.js, state held in memory in the page) lets users tick todos complete, filter All/Active/Completed and clear completed todos. The tests drive the real app in Chromium with Playwright and prove each ticket criterion through user-visible state: strike-through, the "items left" count, the listed items, aria-pressed on the filter buttons, and whether "Clear completed" is shown.

## Scope

**In scope**
- Toggling completion via the checkbox (strike-through + items-left count)
- All / Active / Completed filters and their pressed state
- Clear completed visibility and behaviour

**Out of scope**
- Adding todos (covered by tests/add-todo.spec.js)
- Persistence across reloads (the app keeps todos in memory only; ticket doesn't ask for it)

## Acceptance criteria coverage

| AC | Criterion | Test cases |
|---|---|---|
| AC1 | Ticking a todo's checkbox marks it completed (struck through) and lowers the items-left count by one; unticking reverses both. | TC1, TC2 |
| AC2 | Active shows only uncompleted todos, Completed only completed ones, All shows every todo; the selected filter is shown as pressed. | TC3, TC4, TC5 |
| AC3 | "Clear completed" is shown only while at least one todo is completed, and removes every completed todo. | TC6, TC7 |

## Risks

| Risk | Impact | Mitigation |

| Clear completed removes active todos or is shown with nothing completed | medium | TC6 asserts hidden states, TC7 asserts only active todos remain |

## Test case detail

### TC1: ticking a todo strikes it through and lowers the items left count

*e2e · playwright · positive · critical priority* — covers AC1

**Preconditions**
- Fresh page

**Steps**
1. Add 'Buy milk' and 'Walk dog'
2. Tick 'Buy milk'

**Expected:** 'Buy milk' checkbox is checked and its title has line-through; 'Walk dog' is not struck; count reads '1 item left' (was '2 items left')

**Test data:** Buy milk, Walk dog

**Rationale:** Core completion behaviour

### TC2: unticking a completed todo removes the strike-through and restores the count

*e2e · playwright · positive · high priority* — covers AC1

**Preconditions**
- Fresh page

**Steps**
1. Add two todos
2. Tick 'Buy milk' and see '1 item left'
3. Untick 'Buy milk'

**Expected:** Checkbox unchecked, text-decoration-line none, count '2 items left'

**Test data:** Buy milk, Walk dog

**Rationale:** Reverse transition

### TC3: Active filter shows only todos that aren't completed and is shown as pressed

*e2e · playwright · positive · high priority* — covers AC2

**Preconditions**
- Fresh page

**Steps**
1. Add three todos, tick one
2. Click Active

**Expected:** List shows exactly the two uncompleted todos; Active aria-pressed=true, All and Completed false

**Test data:** Buy milk, Walk dog, Pay rent

**Rationale:** Filter correctness

### TC4: Completed filter shows only completed todos and is shown as pressed

*e2e · playwright · positive · high priority* — covers AC2

**Expected:** List shows exactly the completed todo; Completed pressed, others not

**Test data:** Buy milk, Walk dog, Pay rent

### TC5: All filter shows every todo again after another filter and is shown as pressed

*e2e · playwright · positive · medium priority* — covers AC2

**Preconditions**
- Fresh page

**Steps**
1. Add three todos, tick one

**Expected:** List shows all three todos in order; All pressed, others not

**Test data:** Buy milk, Walk dog, Pay rent

### TC6: Clear completed is hidden while no todo is completed

*e2e · playwright · negative · high priority* — covers AC3

**Preconditions**
- Fresh page

**Steps**
1. Add a todo: Clear completed hidden
2. Tick it: Clear completed visible
3. Untick it

**Expected:** Hidden before ticking, visible after ticking, hidden again after unticking

**Test data:** Buy milk

**Rationale:** Visibility rule both ways

### TC7: Clear completed removes every completed todo and keeps active ones

*e2e · playwright · positive · critical priority* — covers AC3

**Preconditions**
- Fresh page

**Steps**
1. Add three todos, tick two
2. Click Clear completed

**Expected:** List shows only the uncompleted todo; count '1 item left'; Clear completed hidden

**Test data:** Buy milk, Walk dog, Pay rent

**Rationale:** Removes all completed, not just one, and nothing else

## Environment

Playwright starts node server.js on port 4173 via the existing webServer config; BASE_URL http://localhost:4173. Chromium must be installed.

## Assumptions

- The real first-party server (node server.js) runs via the existing playwright.config.js webServer; nothing is faked. There's no backend API or access control.
- Todo state lives in page memory, so each test gets fresh state from its own page and creates its own todos through the UI.
- "Struck through" is checked as the computed text-decoration-line: line-through on the todo's title, not the CSS class.
- Each todo's checkbox has its title as accessible name (label wraps checkbox and text).
