## Summary

Commit 72802a9 ("Show each line's product name on an order") slowed GET /orders/:id: the detail scenario of perf/orders.js went from p95 22 ms to 32 ms and p99 23 ms to 33 ms, and a rerun confirmed it. The route now waits for productNames() as a third store round trip (6–9 ms each), one after the other with findOrder and orderLines. The commit message says the names come "in one query with the lines", but they don't. The plan is to guard this with thresholds tagged to the detail scenario in perf/orders.js, set at the baseline plus 20%, then record and file the defect. The existing thresholds and scenarios stay as they are.
