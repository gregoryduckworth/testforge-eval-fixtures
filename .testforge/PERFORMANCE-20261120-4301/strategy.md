## Summary

The detail scenario in perf/orders.js (GET /orders/:id) slowed from a p95 of 22 ms to 91 ms and a p99 of 25 ms to 95 ms, and a rerun confirmed it. The bisect points to 62d8c6ffbfbb (PR #111), which awaits findProduct once per order line, one after another. Each call is a separate store round trip of 6–9 ms, and an order has 8 lines, so a request makes 8 extra queries. We add thresholds scoped to the detail scenario at the baseline plus 20%, record the defect, and file an issue.
