# Test strategy: SHOP-14 Write a smoke suite of the critical paths, tagged @smoke

Revision 1 · generated by TestForge

## Summary

Add a Playwright smoke suite (tests/smoke.spec.js), every test tagged @smoke in its title, covering the shop's critical paths: health, catalogue, product page, add to cart, cart, checkout and placing an order, plus the refusals on those paths (unknown product, empty cart checkout, empty checkout form). A `test:smoke` script runs only @smoke tests, locally (the config starts the shop) or against a deployed build via BASE_URL.

## Scope

**In scope**
- Smoke tests of the critical paths with Playwright, tagged @smoke in the title
- A test:smoke npm script that runs only @smoke tests
- Making the local webServer port configurable so an already running dev shop on 4175 isn't reused

**Out of scope**
- Changing CI or the deployment pipeline (listed as follow-ups)
- Exhaustive cart/price permutations (not smoke)
- Automated accessibility (axe) scanning: no axe dependency in the repo and the ticket asks for a critical-path smoke suite

## Environment

Locally Playwright starts `node src/server.js` with PORT=E2E_PORT (default 4176). With BASE_URL set, tests run against that build; SMOKE_PLACE_ORDER=1 enables the order test there. Run with `npm run test:smoke`.

## Assumptions

- The real shop runs (started by Playwright's webServer locally, or the deployed build at BASE_URL); nothing is faked. The shop has no login/access control.
- Q1 (asked, unanswered): the place-order test runs when the suite starts the shop locally; with BASE_URL set it is skipped unless SMOKE_PLACE_ORDER=1, so production gets no orders. All other smoke tests are read-only or refused before a request leaves the browser.
- Products, names and prices are imported from src/catalogue.js (PRODUCTS, formatPrice), so a deployed build of the same commit matches.
- The cart is a browser cookie, so each test's fresh browser context gives it its own cart; the placed order is identified by a per-attempt customer name shown on the confirmation.
