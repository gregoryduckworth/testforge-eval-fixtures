# Test strategy: GAPS-20261122-BDE7 Write a smoke suite

Revision 1 · generated by TestForge

## Summary

Kettle & Co. has no smoke tests. Add a small Playwright smoke suite (tests/smoke/shop.spec.js) of read-only checks of the critical paths: the app answers its health check, the catalogue lists what the shop sells, a product page shows its product, adding to the cookie cart shows it in the cart, and checkout opens with the order form. Each test is tagged @smoke, reaches the app only via the configured baseURL (BASE_URL or the locally started shop), and never submits an order.

## Scope

**In scope**
- GET /health
- Catalogue page /
- Product page /products/:id reached from the catalogue
- Add to cart (browser cookie only) and the cart page
- Checkout page with the order form (not submitted)
- A test:smoke npm script that runs only @smoke tests

**Out of scope**
- Placing an order (POST /orders) — it writes data on the server; left to the full e2e suite (tests/checkout.spec.js)
- Order confirmation page — only reachable after placing an order
- Error paths (404, 405, empty-cart checkout) — not smoke
- Automated accessibility (axe) checks — no axe dependency in the repo; smoke suite kept minimal

## Environment

BASE_URL selects a deployed build; without it playwright.config.js starts `node src/server.js` on port 4175. Browsers: `npx playwright install --with-deps chromium` (already in CI).

## Assumptions

- The product list is code (src/catalogue.js PRODUCTS), not seeded data, so every deployed build of this commit shows it; tests import PRODUCTS/formatPrice rather than copying names and prices.
- Adding to cart only writes the browser's cart cookie (public/app.js); no request reaches the server, so it is read-only for the deployment.
- No faking: the real shop runs (started by playwright.config.js webServer locally, or the deployed build via BASE_URL). The app has no login, so no credentials are used.
- This run does not execute the tests (target not disposable); the PR's CI (npx playwright test) runs them against the locally started shop.
