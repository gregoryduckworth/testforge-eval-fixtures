# Test strategy: CART-12 Bulk discount, coupons and free shipping at checkout

Revision 1 · generated by TestForge

## Summary

CART-12 prices the cart at checkout via cartTotal(items, { coupon }) in src/cart.js: a 10% bulk discount at 10+ total items, the SAVE5 coupon after the bulk discount (goods floored at $0) with other codes refused, and $4.99 shipping unless the discounted goods reach $50, with an empty cart costing nothing. Unit tests in Vitest prove each rule at its boundaries through the public cartTotal function, using the exported constants where possible. Reading the code shows the bulk check uses `> BULK_THRESHOLD` (so exactly 10 items get no discount) and the coupon lookup uses `in`, which accepts inherited keys like "toString".

## Test case detail

### TC1: gives 10% off a cart of exactly 10 items spread over several lines

*unit · vitest · edge · critical priority* — covers AC1

**Steps**

**Expected:** 70 subtotal less 7 = 63, free shipping: total 63

**Test data:** two lines, 10 items, $70

**Rationale:** Threshold boundary and quantity summing across lines; code appears to use > instead of >=

## Assumptions

- cartTotal(items, { coupon }) is the checkout pricing entry point; it returns the amount the customer pays (goods after discounts plus shipping), rounded to cents.
- 'Refused with an error' means cartTotal throws; the test checks the thrown message contains the submitted code (the part the test controls).
- Coupon codes are case-sensitive (only exactly 'SAVE5' is valid), as the code implements; the ticket names the code exactly.
- An 'empty cart' is an items array with no lines.
