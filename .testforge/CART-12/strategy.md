# Test strategy: CART-12 Bulk discount, coupons and free shipping at checkout

Revision 1 · generated by TestForge

## Summary

CART-12 prices the cart at checkout via cartTotal(items, { coupon }) in src/cart.js: 10% bulk discount at 10+ items in total, SAVE5 coupon taking $5 off after the bulk discount (floored at $0), unknown coupons refused, and free shipping when discounted goods reach $50 (else $4.99; empty cart costs 0). Unit tests on cartTotal must prove each rule and its boundaries. Reading the code shows two likely defects: the bulk discount uses `> 10` (exactly 10 items get no discount), and coupon lookup uses `in`, so inherited keys like "constructor" are accepted instead of refused.

## Scope

**In scope**
- cartTotal pricing: bulk discount, SAVE5 coupon, coupon refusal, shipping rules, empty cart
- Boundaries: 9/10 items, $49.99/$50 goods, coupon larger than goods

**Out of scope**
- UI or API checkout flows (none exist in this repo)

## Test case detail

### TC1: gives 10% off a cart of exactly 10 items

*unit · vitest · edge · critical priority* — covers AC1

**Steps**
1. cartTotal([{price:3,quantity:10}])

**Expected:** 31.99 (30 - 3 + 4.99 shipping). Expected to fail: code requires more than 10 items

**Test data:** 10 x $3

**Rationale:** Threshold boundary; code reads > 10
