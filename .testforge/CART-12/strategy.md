# Test strategy: CART-12 Bulk discount, coupons and free shipping at checkout

Revision 1 · generated by TestForge

## Summary

cartTotal in src/cart.js prices a cart with a 10% bulk discount, the SAVE5 coupon (after the bulk discount, floored at $0) and $4.99 shipping below $50 of discounted goods. Unit tests through cartTotal prove each rule and its boundaries. Reading the code, the bulk discount uses `itemCount > BULK_THRESHOLD`, so a cart with exactly 10 items gets no discount. That contradicts AC1 and the code's own doc comment ("at least this many"), so it is expected to show up as a defect.

## Scope

**In scope**
- cartTotal pricing: bulk discount, coupon, shipping, empty cart
- Boundaries: 9/10/11 items, $50 goods, $0 floor

**Out of scope**
- Line-total rounding beyond what existing subtotal tests cover

| AC | Criterion | Test cases |

| Risk | Impact | Mitigation |

## Assumptions

- Coupon codes are case-sensitive: 'save5' is an 'other code' and is refused (code uses an exact key lookup).
- A refusal is a thrown Error; tests check that it is thrown and that its message names the submitted code, since the code has no error class or code.
- A non-empty cart whose goods are $0 after the coupon still pays $4.99 shipping (AC3: goods below $50; only an empty cart is free).
