# Test strategy: CART-12 Bulk discount, coupons and free shipping at checkout

Revision 1 · generated by TestForge

## Summary

CART-12 prices the cart at checkout in src/cart.js (cartTotal, bulkDiscount): 10% bulk discount at 10+ items in total, the SAVE5 coupon after the bulk discount with goods floored at $0, other coupons refused, and $4.99 shipping unless discounted goods reach $50 (empty cart costs $0). Unit tests with vitest must prove each rule and its boundaries. Reading the code shows two likely defects: bulkDiscount uses `> BULK_THRESHOLD` (exactly 10 items gets no discount), and the coupon check uses `in`, so inherited names such as `toString` are accepted rather than refused.

**In scope**
- cartTotal and bulkDiscount in src/cart.js: bulk discount, coupon, shipping rules and their boundaries

**Out of scope**
- UI/checkout pages (none exist in this repo)

## Environment

## Assumptions

- Refusing a coupon means cartTotal throws; the test identifies the refusal by the code it submitted appearing in the error message, since there is no error code.
- Coupon codes are case-sensitive as written in the ticket (SAVE5); a cart with items whose goods are reduced to $0 still pays $4.99 shipping, per AC3's 'otherwise'.
- Failing assertions that match the ticket but not the code are kept and marked it.fails, with record_defect.

## Open questions

- Should coupon codes be case-insensitive (e.g. 'save5')? The code treats them as case-sensitive; not tested.
- Should a coupon of an empty string or null be refused or treated as no coupon? Not tested.
