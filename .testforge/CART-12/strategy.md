# Test strategy: CART-12 Bulk discount, coupons and free shipping at checkout

Revision 1 · generated by TestForge

## Summary

CART-12 prices the cart at checkout via `cartTotal(items, { coupon })` in src/cart.js: 10% bulk discount at 10+ items in total, the SAVE5 coupon ($5 off after the bulk discount, goods floored at $0, other codes refused), and $4.99 shipping that is free from $50 of discounted goods (an empty cart costs $0). Unit tests in Vitest need to show each rule and its boundaries. Reading the code turned up two likely defects. The bulk check uses `>` where the ticket says 10 or more. The coupon lookup uses `in`, so prototype keys such as `toString` are accepted instead of refused.

## Scope

**In scope**
- cartTotal pricing: bulk discount, SAVE5 coupon, coupon refusal, shipping threshold, empty cart

**Out of scope**
- UI/checkout pages (none exist in the repo)

## Risks

| Risk | Impact | Mitigation |
|---|---|---|
| Off-by-one at the bulk threshold: the code uses `itemCount > 10`, so a cart of exactly 10 items gets no discount | high | TC2 checks exactly 10 items split across lines; kept as an expected failure with a recorded defect if it fails |
| The coupon lookup uses the `in` operator, so prototype keys ('toString', 'constructor') pass validation and produce a NaN total | medium | TC7 checks that 'toString' is refused |
| The coupon could be applied before the bulk discount, or shipping judged on the pre-discount subtotal | high | TC4 and TC9 use amounts where the wrong order or threshold gives a different total |

## Environment

Pure unit tests; no services needed. Run with `npm test`.

## Assumptions

- Item counts add up each line's quantity, as itemCount does.
- Coupon codes are case-sensitive: only the exact string 'SAVE5' is valid, since the ticket says any other code is refused.
- A refused coupon is signalled by cartTotal throwing an Error; tests check it throws and that the message names the code submitted.

## Open questions

- Should coupon codes be case-insensitive (e.g. 'save5')? Tests assume they are not.
