# Test strategy: CART-12 Bulk discount, coupons and free shipping at checkout

Revision 2 · generated by TestForge

## Summary

CART-12 prices the cart at checkout: 10% bulk discount at 10+ items (summed over line quantities), the SAVE5 coupon ($5 off after the bulk discount, floored at $0, other codes refused), and $4.99 shipping unless discounted goods reach $50 (empty cart costs nothing). All logic is in src/cart.js (cartTotal, bulkDiscount); tests are Vitest unit tests through cartTotal. bulkDiscount uses `itemCount > BULK_THRESHOLD`, so exactly 10 items gets no discount, contradicting AC1 — that case is expected to fail and is reported as a defect. Revision 2 adds TC12 (SAVE5 taking goods to exactly $0) from PR review feedback.

## Scope

**In scope**
- cartTotal pricing: bulk discount, SAVE5 coupon, unknown coupons, shipping threshold, empty cart
- Boundaries: 9/10 items, $49.99/$50 goods, coupon equal to and larger than goods

**Out of scope**
- Any UI or API around checkout (none exists in the repo)
- Currency rounding beyond the values the cases use

## Test case detail

### TC1: gives 10% off a cart of exactly 10 items

*unit · vitest · edge · critical priority* — covers AC1

**Steps**
1. cartTotal([{ price: 10, quantity: 10 }])

**Expected:** 90 (100 less 10%, free shipping)

**Test data:** one line, $10 x 10

**Rationale:** Threshold boundary; code uses > so this is expected to fail (defect)

### TC3: counts items by adding up each line's quantity for the bulk discount

## Assumptions

- cartTotal(items, { coupon }) is the checkout price; items are { price, quantity } as in the existing test
- Coupon refusal is a thrown Error; tests check the message names the submitted code (the part the test controls)
- A cart whose coupon floors the goods at $0 still pays $4.99 shipping, since only an empty cart is shipped free below $50
- Coupon codes are matched exactly (case-sensitive), as the code does
- Totals that go through the 10% discount are compared to the cent with toBeCloseTo(value, 2), per PR review

## Open questions

- Should a coupon bringing goods to $0 on a non-empty cart still be charged $4.99 shipping? The code and a literal reading of AC3 say yes.
