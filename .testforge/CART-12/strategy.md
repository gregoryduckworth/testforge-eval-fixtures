# Test strategy: CART-12 Bulk discount, coupons and free shipping at checkout

Revision 1 · generated by TestForge

## Summary

CART-12 prices the cart at checkout via cartTotal() in src/cart.js: a 10% bulk discount for 10+ items (summed over line quantities), the SAVE5 coupon ($5 off after the bulk discount, floored at $0, other codes refused), and $4.99 shipping unless discounted goods reach $50 (empty cart is free). Unit tests in Vitest prove each rule and its boundaries through the public cartTotal function, importing the thresholds from the code. Reading the code shows bulkDiscount uses `> BULK_THRESHOLD`, so a cart of exactly 10 items gets no discount — contrary to AC1 and to the function's own doc comment ("at least this many"); that case will be kept as an expected failure and reported as a defect.

## Scope

**In scope**
- cartTotal() in src/cart.js: bulk discount, SAVE5 coupon, unknown coupon refusal, shipping threshold, empty cart
- Boundaries: exactly 10 / 9 items, goods exactly $50 / $49.99, goods floored at $0

**Out of scope**
- Any UI or API checkout flow (the repo is a pure pricing library)

## Assumptions

- Prices and the result are dollars as numbers rounded to cents by the module, so toBe on the expected rounded value is exact.
- 'Refused with an error' means cartTotal throws; the test checks the thrown message names the code submitted (the part the test controls).
- Coupon codes are case-sensitive: 'save5' is a different code and is refused (the ticket says any other code is refused).
- A non-empty cart whose goods drop to $0 through the coupon still pays $4.99 shipping, as AC3 says shipping is $4.99 whenever goods are under $50 and only an empty cart costs nothing.

## Open questions

- Should a non-empty cart that a coupon brings to $0 still pay $4.99 shipping? The code and AC3's wording say yes; the tests assert that.
