# Test strategy: CART-12 Bulk discount, coupons and free shipping at checkout

Revision 1 · generated by TestForge

## Summary

CART-12 prices the cart in src/cart.js `cartTotal(items, { coupon })`: 10% bulk discount at 10+ items (summed quantities), SAVE5 coupon taking $5 after the bulk discount with goods floored at $0, unknown coupons refused, and shipping free from $50 of discounted goods, else $4.99, with an empty cart costing nothing. Unit tests in Vitest prove each rule and its boundaries through `cartTotal`. Reading the code shows `bulkDiscount` uses `> BULK_THRESHOLD`, so a cart of exactly 10 items gets no discount: that case is expected to fail and will be recorded as a defect.

## Scope

**In scope**
- cartTotal, bulkDiscount pricing rules in src/cart.js
- Boundaries: 9/10/11 items, $50 shipping threshold, $0 floor, empty cart

**Out of scope**
- UI or API checkout (none exists in the repo)
- Rounding of fractional cents beyond the cases above

## Assumptions

- Coupon codes are case-sensitive as the code implements (only exactly 'SAVE5' is accepted).
- A non-empty cart whose goods are floored to $0 by the coupon still pays $4.99 shipping, since only an empty cart is stated to cost nothing.
- Refusal is the thrown Error from cartTotal; tests check the message contains the submitted code.
