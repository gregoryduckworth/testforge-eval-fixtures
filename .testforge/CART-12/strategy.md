# Test strategy: CART-12 Bulk discount, coupons and free shipping at checkout

Revision 1 · generated by TestForge

## Summary

CART-12 prices the cart at checkout via cartTotal(items, { coupon }) in src/cart.js: 10% bulk discount at 10+ items (summed quantities), SAVE5 coupon applied after the bulk discount with goods floored at $0, unknown coupons refused, and $4.99 shipping unless discounted goods are $50+ (empty cart is free). Unit tests in Vitest must prove each rule and its boundaries through cartTotal's returned total. Reading the code: bulkDiscount uses `itemCount > BULK_THRESHOLD`, so a cart of exactly 10 items gets no discount, contradicting AC1 and the constant's own doc comment ("at least this many"); that case is planned as an expected failure with a defect report.

## Scope

**In scope**
- cartTotal, bulkDiscount behaviour as seen in cartTotal's result
- Bulk-discount threshold boundaries (9, 10, 11 items across several lines)
- SAVE5 ordering after the bulk discount and the $0 floor on goods
- Refusal of unknown coupon codes
- Free-shipping threshold boundaries based on discounted goods, empty cart

**Out of scope**
- UI or API for checkout (none exists in the repo)
- Other coupon codes beyond SAVE5 (ticket defines only SAVE5)

## Environment

Pure unit tests; no services. Run with npm test (vitest run).

## Assumptions

- cartTotal(items, { coupon }) is the checkout pricing entry point; items are { price, quantity }.
- Totals are rounded to cents by the code, so exact toBe comparisons on dollar amounts are used.
- Coupon codes are case-sensitive (only 'SAVE5' exists in the code); 'save5' is treated as another code and refused.
- A refused coupon is signalled by cartTotal throwing an Error whose message names the submitted code.

## Open questions

- Should the coupon be accepted case-insensitively (e.g. 'save5')? The code refuses it; tests follow the code.
- With SAVE5 on a cart under $5, goods become $0 but shipping $4.99 still applies (the code's behaviour; ticket only says goods never cost less than $0).
