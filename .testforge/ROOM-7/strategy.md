# Test strategy: ROOM-7 Book meeting rooms

Revision 1 · generated by TestForge

## Summary

ROOM-7 covers createBookings(): it validates bookings (room, owner, half-hour UTC start, a length of 30–240 min in 30-min steps), refuses overlaps within the same room, lists a room's bookings by start time, and lets only the owner cancel. Vitest unit tests against the real module with memoryStore() must prove each rule and its refusal, checking the BookingError message that says why.

## Scope

**In scope**
- book() validation and refusals
- overlap rules
- list() ordering
- cancel() permission and freeing time

**Out of scope**
- The app's database BookingStore (not in repo)
