# Test strategy: GAPS-20261122-2759 Guard the pages that pass with axe checks

Revision 1 · generated by TestForge

## Summary

TestForge's axe scan found no violations on `/` and `/contact`, and no e2e test runs axe on either page yet. This change adds an axe check for each page as a new test in the spec that already covers it (tests/home.spec.js and tests/contact.spec.js), using @axe-core/playwright, which is already a devDependency. Each check fails on any violation of minor impact or worse, which covers every impact axe reports, and names each rule and the elements it failed on. The application and the existing tests are not changed, and the known violations on /about and /cart are left alone.
